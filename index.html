CSS

What is the CSS Box Model order?

Click to flip 🔄

Inside to Outside:

1. Content (text/image)
2. Padding (inner spacing)
3. Border (frame line)
4. Margin (outer separation from others)

JavaScript

Difference between `==` and `===`?

Click to flip 🔄

Equality Comparison:

== compares values with type coercion (e.g. 5 == "5" is true).

=== compares both value AND type strictly (e.g. 5 === "5" is false).

Python

List vs. Tuple in Python?

Click to flip 🔄

Mutability:

List `[]`: Mutable (can add, remove, change items).

Tuple `()`: Immutable (cannot be modified after creation, faster & safer for fixed data).

Git

What does `git pull` do?

Click to flip 🔄

Fetch + Merge:

`git pull` fetches remote changes from GitHub and automatically merges them into your current local branch in one step.

💡 Suggested 15-Minute Classroom Interventions

  • Activity 1 (CSS Box Model): Have students open Chrome DevTools on their favorite website, inspect elements, and colorize margins (orange) vs padding (green) to visually solve spacing confusion.
  • Activity 2 (JS Async): Run a physical roleplay: One student acts as the "Call Stack", another as the "Web API timer", and a third as the "Callback Queue" to physically simulate asynchronous execution.
  • Activity 3 (Hackathon Prep): Group students into 3-person squads and mandate creating an MVP with no more than 2 screens within a 45-minute lab session.
